R.I.D.E. ESP32-C3 Super Mini Prototype
####################################

This board definition targets the ESP32-C3 Super Mini prototype used by
R.I.D.E. Mk1. Its console and Zephyr Shell use the ESP32-C3 native USB
Serial/JTAG controller (typically ``/dev/ttyACM0`` on Linux).

This is not the final R.I.D.E. custom PCB pinout. No physical button,
display, or sensor GPIO assignments are defined yet.
